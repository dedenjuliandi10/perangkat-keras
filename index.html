Pengertian Perangkat Keras (Hardware)

Mengenal wujud fisik komputer dan perbandingannya
💬

“Perangkat keras komputer atau hardware adalah bagian komputer yang dapat dilihat dan disentuh secara langsung.”

🖥️

HARDWARE (Perangkat Keras)

  • ✨ Memiliki bentuk fisik yang nyata.
  • ✋ Dapat dilihat dan disentuh langsung dengan tangan.
  • 📌 Berperan mengeksekusi perintah secara elektrik/mekanis.
  • 💡 Contoh: Keyboard, Mouse, Monitor, CPU, Printer, Speaker, Flashdisk, Hard disk.
💿

SOFTWARE (Perangkat Lunak)

  • ✨ Tidak memiliki bentuk fisik padat.
  • 👀 Hanya dapat dilihat di layar, tidak bisa disentuh langsung.
  • 📌 Kumpulan data, program, atau perintah digital komputer.
  • 💡 Contoh: Sistem Operasi (Windows), Web Browser (Chrome), Game, Aplikasi Office.
🎒 Contoh Nyata di Sekolah:

“Ketika mengetik tugas sekolah, kita menggunakan keyboard untuk memasukkan huruf ke layar. Keyboard tersebut merupakan perangkat keras karena kita dapat memegangnya langsung.”

B

Perangkat Input (Input Device)

Pintu masuk data dan instruksi dari kita ke komputer
📥

“Perangkat input adalah perangkat yang digunakan untuk memasukkan data atau perintah ke komputer.”

⌨️

Keyboard

Fungsi: Digunakan untuk memasukkan huruf, angka, simbol, dan perintah teks.

💡 Contoh: Mengetik tugas sekolah atau kode pemrograman.
🖱️

Mouse

Fungsi: Menggerakkan penunjuk (kursor/pointer) dan memilih menu di layar.

💡 Contoh: Mengklik ikon aplikasi atau menggambar.
🎤

Microphone

Fungsi: Memasukkan sinyal suara ke dalam komputer.

💡 Contoh: Berbicara saat belajar online / zoom kelas.
📷

Webcam

Fungsi: Menangkap rekaman gambar dan video pengguna secara langsung.

💡 Contoh: Video call pembelajaran jarak jauh.
🖊️

Scanner

Fungsi: Memindai dokumen fisik kertas atau foto menjadi gambar digital.

💡 Contoh: Mengunggah berkas piagam atau fotokopi tugas.
🎮

Joystick / Gamepad

Fungsi: Memasukkan perintah kendali arah dan aksi dalam permainan/simulasi.

💡 Contoh: Mengontrol karakter game edukasi.
📱

Touchscreen

Fungsi: Layar sentuh yang menerima input langsung dari sentuhan jari siswa.

💡 Contoh: Menavigasi tablet belajar atau smartphone.
❓

Uji Pemahaman Cepat:

“Perangkat apa yang digunakan untuk mengetik teks dan angka ke komputer?”

C

Perangkat Proses (Processing Device)

Pusat komputasi dan pengolahan seluruh instruksi
⚙️

“Perangkat proses adalah perangkat yang mengolah data dan menjalankan perintah dari pengguna.”

🧠

CPU / Processor

Central Processing Unit

CPU dapat dianggap sebagai otak komputer yang menjalankan berbagai perintah dan operasi matematika logika dengan kecepatan sangat tinggi.

💡 Analogi: Seperti otak manusia yang berpikir dan mengambil keputusan.
⚡

RAM

Random Access Memory

RAM adalah tempat penyimpanan sementara yang membantu komputer menjalankan program dengan lancar. Data di RAM hilang saat komputer dimatikan (bersifat volatile).

💡 Analogi: Seperti meja belajar tempat kita membuka buku yang sedang kita baca.
🎨

GPU / VGA Card

Graphics Processing Unit

GPU bertugas khusus mengolah tampilan grafis, video, dan gambar agar visual 3D, animasi, dan video bergerak dengan jernih dan mulus.

💡 Analogi: Seperti seniman visual yang melukis ribuan piksel warna tiap detik.
🖲️

Motherboard

Mainboard / Papan Utama

Motherboard adalah papan utama tempat semua komponen komputer (CPU, RAM, VGA, Penyimpanan) terpasang dan saling berkomunikasi lewat jalur sirkuit listrik.

💡 Analogi: Seperti jaringan jalan raya yang menghubungkan semua gedung di kota.
INPUT ⌨️ 🖱️ Keyboard / Mouse Pengguna mengetik/mengklik
Instruksi Masuk
➔
PROCESS 🧠 ⚡ 🎨 CPU / RAM / GPU Mengolah & Menghitung data
Hasil Siap

D

Perangkat Output (Output Device)

Media penyampai hasil pengolahan data kepada kita
📤

“Perangkat output adalah perangkat yang digunakan untuk menampilkan atau menghasilkan informasi dari komputer.”

🖥️

Monitor

Fungsi: Menampilkan gambar, teks, video, dan antarmuka informasi dari komputer.

💡 Contoh: Melihat hasil ketikan tugas atau menonton video materi.
🖨️

Printer

Fungsi: Mencetak tulisan, diagram, atau gambar digital ke media kertas fisik (hardcopy).

💡 Contoh: Mencetak lembar kerja siswa atau makalah tugas.
🔊

Speaker

Fungsi: Mengeluarkan gelombang suara hasil pengolahan audio komputer.

💡 Contoh: Mendengarkan penjelasan guru atau audio edukasi di kelas.
🎧

Headset / Earphone

Fungsi: Mengeluarkan suara khusus untuk telinga satu pengguna secara jernih.

💡 Contoh: Mendengarkan audio saat ujian listening bahasa di lab.
📽️

Projector (InFocus)

Fungsi: Memproyeksikan tampilan layar monitor ke layar kain/tembok besar.

💡 Contoh: Guru mempresentasikan slide materi di depan kelas.
E

Perangkat Penyimpanan (Storage Device)

Tempat menyimpan berkas dan file agar aman & dapat dibuka kembali
💾

“Perangkat penyimpanan digunakan untuk menyimpan data agar dapat digunakan kembali secara permanen (non-volatile).”

🔒

Penyimpanan Internal

Terpasang di dalam badan komputer/laptop
  • HDD (Hard Disk Drive): Menggunakan piringan magnetik berputar, kapasitas besar dengan harga terjangkau.
  • SSD (Solid State Drive): Menggunakan chip memori flash berkecepatan sangat tinggi, tahan guncangan, dan hemat daya.
🎒

Penyimpanan Eksternal

Mudah dicabut dan dibawa bepergian
  • Flashdisk (USB Drive): Praktis dimasukkan saku untuk memindahkan tugas sekolah antar komputer.
  • Memory Card (MicroSD): Kartu kecil untuk smartphone, kamera digital, atau tablet.
  • CD / DVD: Media penyimpanan piringan optik yang dibaca menggunakan sinar laser.
📊 Tabel Karakteristik Perangkat Penyimpanan:
Ikon Perangkat Kategori Fungsi Pokok Keunggulan
🖴 HDD Internal Menyimpan data sistem & berkas Kapasitas sangat besar (1 TB - 4 TB), harga ekonomis
⚡ SSD Internal Menyimpan data dengan akses cepat Booting komputer hitungan detik, tanpa komponen berputar
🔌 Flashdisk Eksternal Menyimpan dan memindahkan data Kecil, praktis dicolok ke port USB mana saja
🃏 Memory Card Eksternal Menyimpan data pada perangkat tertentu Ukuran sangat mungil, cocok untuk smartphone & kamera
💿 CD / DVD Eksternal Menyimpan data menggunakan media optik Bagus untuk arsip master musik/software permanen
F

Perangkat Komunikasi / Jaringan (Networking)

Jembatan penghubung antar komputer dan dunia internet
🌐

“Perangkat komunikasi atau jaringan digunakan untuk menghubungkan komputer dengan perangkat lain atau jaringan internet.”

📶

Modem

Mengubah sinyal analog dari penyedia layanan internet menjadi sinyal digital yang dipahami komputer (dan sebaliknya).

📡

Router

Mengatur rute lalu lintas data dan menghubungkan beberapa perangkat ke internet (sering memancarkan Wi-Fi).

🔀

Switch

Menghubungkan banyak komputer dalam satu jaringan lokal (LAN) di laboratorium komputer sekolah menggunakan kabel.

📻

Access Point

Memancarkan sinyal nirkabel (Wi-Fi) agar laptop dan gawai siswa dapat terhubung ke jaringan tanpa kabel.

🔌

LAN Card / NIC

Kartu antarmuka pada komputer tempat mencolokkan kabel jaringan (port RJ-45) agar dapat berkomunikasi.

G

Cara Kerja Perangkat Keras Komputer

Bagaimana keempat pilar perangkat bekerja sama tanpa henti

Seluruh perangkat keras komputer bekerja bersama dalam satu siklus yang harmonis: INPUT ➔ PROCESS ➔ OUTPUT ➔ STORAGE.

📖 Contoh Skenario Nyata: Siswa Mengetik Tugas Makalah
1
⌨️ Keyboard (Input)

Siswa menekan tombol huruf "B-U-K-U" pada papan ketik.

2
🧠 CPU & RAM (Proses)

CPU menerjemahkan sinyal listrik menjadi kode teks dan RAM menyimpannya sementara di memori kerja.

3
🖥️ Monitor (Output)

Layar monitor langsung menampilkan kata "BUKU" dalam sekejap mata.

4
💾 SSD / Flashdisk (Storage)

Ketika siswa menekan tombol simpan (Save), berkas tugas tersimpan rapi di dalam SSD agar tidak hilang.

INTISARI MATERI

Rangkuman Perangkat Keras Komputer

Poin-poin pokok dan tabel rujukan penting untuk dipelajari kembali di rumah maupun di kelas.

📌

6 Kesimpulan Utama Materi:

✓
Hardware adalah bagian fisik komputer yang dapat dilihat dan disentuh secara nyata, bertindak sebagai pelaksana perintah pengguna.
✓
Perangkat Input (seperti keyboard, mouse, scanner, mikrofon) digunakan untuk memasukkan data dan instruksi ke komputer.
✓
Perangkat Proses (seperti CPU sebagai otak, RAM sebagai memori kerja, GPU sebagai pengolah visual) bertugas mengolah instruksi data.
✓
Perangkat Output (seperti monitor, printer, speaker, proyektor) digunakan untuk menyajikan hasil pengolahan kepada pengguna.
✓
Perangkat Storage (seperti SSD, HDD, Flashdisk) bertugas menyimpan berkas, file, dan sistem agar tidak hilang saat komputer mati.
✓
Perangkat Network (seperti router, modem, switch) menghubungkan komputer satu dengan lainnya ke jaringan lokal atau internet global.
